
# Word & Line Counter CLI

A small Node.js CLI that reads a text file and prints the number of lines, words, and characters.

## Requirements
- Node.js 18+

## Usage
```bash
npm start <filename>
```

## Example
```bash
npm start sample.txt
```

Output:
```text
File: sample.txt
Lines: 10
Words: 67
Characters: 406
```
EOF
